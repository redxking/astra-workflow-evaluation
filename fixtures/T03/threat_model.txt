Synthetic benchmark; MIT.
This is the full security gate for POST writes; no upstream security checks. Input strings are parsed and keys always exist. Host is exactly the raw canonical DNS host without port; proxy rewriting is out of scope. An attacker can choose request field values including Origin and CSRF, and may possess a victim session ID through a browser sending its cookie. A session dictionary has authenticated (bool), user_id, csrf_token. Sessions may exist before login with authenticated=false and a provisional user_id. Every POST requires an authenticated session, an Origin exactly equal to EXPECTED_ORIGIN, and a nonempty csrf value exactly equal to session csrf_token. perform_write executes a protected change. GET returns only a public static document and performs no write or private-data access. All other methods must be rejected. A candidate is an issue iff its implementation violates these explicit requirements. Do not assume real browser header restrictions narrow this stated test model.
