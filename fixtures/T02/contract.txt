Synthetic benchmark; MIT.
Inputs are guaranteed: entries is a list of dicts containing exactly path (str), size (int, never bool), sha256 (str); blobs is a dict from str to bytes; limits are integers, never bool. Inputs are small. Do not mutate inputs.
Reject negative limits and negative declared sizes. A canonical path is a nonempty relative POSIX path: no leading/trailing slash, empty components, dot or dot-dot components, backslash, or NUL. Reject repeated entry paths. For each entry, blobs must contain that path. Extra blob keys are allowed and ignored. The actual byte length must equal declared size. Digest must be exactly 64 lowercase hexadecimal characters and match SHA-256 of actual bytes. Reject actual length greater than per_file_limit or aggregate actual bytes greater than total_limit. Equality at both limits is allowed. Empty snapshots and zero-byte files are allowed. On rejection raise ValueError (message unrestricted). On success return exactly {"files": number of entries, "total_bytes": aggregate actual bytes}. Do not use assertions for validation.
